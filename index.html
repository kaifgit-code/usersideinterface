📖 How to Use Shramsahyog

Simple step-by-step working of the platform.

👤 Customer

Login/Create Account → Choose Service → Describe Problem → Find Verified Worker → Worker Accepts → Track Worker → Physical Inspection → Quotation → Accept/Reject → Payment → Service Completed → Rating & Review.

👨‍🔧 Worker

Create Worker Account → KYC & Trade Certificate Verification → Select Skill → Receive Request → Accept Request → Go to Customer Location → Inspection → Transparent Quotation → Complete Service → Customer Rating.

🛡️ Worker Verification

Worker registration includes KYC status and Trade/Skill Certificate information. In the production app, actual verification will use an authorised verification provider.

📍 Tracking

Customer can follow the worker journey: Worker Accepted → On the Way → Reached Location → Inspection → Quotation → Payment → Service Completed.

💰 Transparent Pricing

After inspection, the customer receives an itemized quotation before approving the service. The customer can accept or reject the quotation.
